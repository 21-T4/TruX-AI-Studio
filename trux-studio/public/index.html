Endpoints

POST /v1/chat/completions Chat with a model. Supports stream: true.

GET /v1/models List available models.

Request body

model one of the model ids below. messages list of {role, content} with roles system, user, assistant. Optional: temperature (0 to 2), top_p (0 to 1), max_tokens, stream.

Limits and errors

Requests are limited per minute and per day depending on the model. 401 bad or missing key, 429 limit reached or model busy, 400 invalid request, 502 model temporarily unavailable.
